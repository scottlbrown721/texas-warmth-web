# San Antonio Care Connect

Build a polished, conversion-focused website for a San Antonio and Bexar County non-medical in-home care provider using the supplied requirements. Include the exact top notification, hero messaging and two CTAs, trust badges, service overview cards, Gloria's Difference, a Texas non-medical compliance notice, detailed service content for Personal Care, Companion & Homemaker, and Facility Staffing for ALFs/SNFs. Make it responsive, credible, warm, and optimized for local SEO.
